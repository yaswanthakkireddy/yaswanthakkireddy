# Portrait and motion direction

Visual inspiration reviewed: [Gargi Bharadwaj](https://github.com/bgargy), [DenverCoder1](https://github.com/DenverCoder1), [Anurag Hazra](https://github.com/anuraghazra), [Abhishek Naidu](https://github.com/abhisheknaiidu), [GitHub Profile Console](https://github.com/wildanniam/GitHub-Profile-Console) and [Dither Portrait](https://github.com/0xharkirat/dither-portrait).

Original design uses near-black #05070e, orange-red #ff4b2e, neon green #a3ff39, electric blue #00c8ff and yellow #ffd537. The actual public GitHub avatar is embedded unchanged in self-contained SVG headers. No fictional portrait, accomplishment, certification or visitor counter is generated.

Motion stays inside SVGs: typing reveal, slow portrait rim, moving system traces and footer signal. Static identity and project evidence remain visible. Composite cards give desktop a grid and mobile a readable stack. Text links outside SVGs remain accessible.

To refresh the avatar, run Build portrait header from GitHub Actions. It updates only when generated bytes change. There is no daily portrait timestamp.
