# Blue and mint profile

The README artwork uses deep navy #07141f, blue #53bfff and mint #9ff5d5. The actual avatar and source UI screenshots are preserved.

GitHub controls the native pinned repositories, contribution calendar and page background. The selected-repository gallery and Contribution Signal are customized README sections. Repository About descriptions and pin order still require GitHub settings.

Contribution Signal reads GitHub's public 2026 calendar. Cells reflect GitHub intensity levels; bars count active contribution days per month. It does not infer commit totals, private activity, developer rank or productivity. Automation may be included by GitHub. Snapshots omit fetch dates and zero-intensity rows, so the passing of a day alone does not create a commit. API or validation failures preserve prior assets.
